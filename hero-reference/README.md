## Acceptance criteria (from design review)

1. Glass must be ~95% transparent — only polished edges, subtle
   reflections, thin refraction and soft highlights are visible.
   Never opaque white/plastic faces.
2. Typography carries hierarchy and luxury (Satoshi, tight tracking,
   metallic gradient focal line).
3. The scene reads as FROZEN TIME, not floating meshes — shard
   self-motion barely perceptible.
4. Motion comes from cinematic camera movement (idle drift + damped
   cursor orbit), never object animation.
5. Lighting resembles premium product photography: key + warm rim +
   faint fill. No flat wash.
6. Shards frame the typography. They never cover important text.
7. Warmth (gold) appears only through reflections and typography —
   never as large colored surfaces.
8. If a change makes it feel like a Three.js demo, remove the change.
